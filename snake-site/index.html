One snake game. Way too many ideas.

What started as a joke ("Snake, but with way too many features") actually shipped all of them.

🎮

8 game modes

Classic wraparound, deadly Walls, growing Maze obstacles, 2-rival Battle, 60s Timed attack, one-life Hardcore, local 2-player Coop, and a seeded Daily Challenge.

🌀

Power-ups & portals

Ghost, Magnet, Shield, Slow-mo, 2x Score, Freeze, and instant Teleport — plus teleport portal pairs and a cursed food that reverses your controls.

🌐

LAN multiplayer

Host a match on your local network — no server, no account. Your friend joins by typing your LAN IP and plays as a synced second snake in real time.

🗺️

8 maps, every mode

Pick a board layout before any match — including Coop and solo modes, not just LAN. Volcano, Everest, Desert and Glacier each have their own obstacle shapes, tint, and ambient particles (embers, snow, sand, sparkle).

🪙

Coins, quests & a shop

Earn coins every run, clear 3 new daily quests, build a play streak, and spend it all on cosmetic trail effects — including an animated Rainbow trail.

🏆

Achievements with progress

12 achievements with live progress bars (not just checkmarks), unlockable skins, and a real-time "New Personal Best" banner mid-run.

👻

Race your own ghost

Every mode remembers your best run and replays it as a ghost, showing live whether you're ahead or behind. Plus an arcade top-10 with 3-letter initials.

🔄

Auto-updater

Checks for new versions on launch and offers to download and install them for you — no need to come back to this page every time.

Pick your chaos

Every mode reuses the same core systems — combos, power-ups, achievements — with its own twist.

Getting started

  • Download

    Grab the build for your OS above. Nothing to install — Windows/Linux are a single portable file, macOS is a zipped .app.

  • Run it

    Windows: double-click; SmartScreen may warn since it's unsigned — click "More info" → "Run anyway."
    macOS: unzip, drag MegaSnake.app into your Applications folder (needed for auto-updates), then right-click it → Open (first time only) to bypass Gatekeeper.
    Linux: chmod +x MegaSnake-Linux && ./MegaSnake-Linux

  • Play

    Arrow keys or WASD to move. New? Open How to Play from the main menu for every food and power-up. Color-blind mode is in Settings.

  • Invite a friend

    Open Multiplayer → Host LAN Game, and have them join using the IP shown on your screen (same Wi-Fi/network).

Note: progress (coins, achievements, leaderboard) saves locally to a .megasnake folder in your user profile. LAN games save to the host's save file only.
