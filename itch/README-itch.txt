MEGA SNAKE  -  snake, but with way too many features
=====================================================

Run it:
  Windows : double-click MegaSnake.exe
            (SmartScreen may warn about an unsigned app: "More info" > "Run anyway")
  macOS   : open MegaSnake.app
            (if macOS blocks it, right-click the app > Open > Open)
  Linux   : run ./MegaSnake   (if it won't start: chmod +x MegaSnake)

Updates: this copy is updated through itch.io (the itch app does it for you). The
in-game updater is switched off in itch builds.

Saves live in a folder called .megasnake in your home directory.
